# Model ecosystem logo sources

These marks identify their respective projects and vendors on the
Model Agnosticism slide. Trademarks remain the property of their owners.

- Simple Icons CDN: scikit-learn, PyTorch, TensorFlow, Apache Spark, pandas,
  Hugging Face, Anthropic, LangChain, and Haystack.
- Iconify `logos` collection: Microsoft Azure and OpenAI.
- XGBoost project site: `https://xgboost.ai/images/logo/xgboost-logo-trimmed.png`
- statsmodels repository:
  `docs/source/images/statsmodels-logo-v2-no-text.svg`
- JAX repository: `images/jax_logo.svg`
- DSPy repository: `docs/docs/static/img/dspy_logo.png`
- MosaicML LLM Foundry repository: `assets/llm-foundry.png`
- txtai repository: `logo.png`

“Custom APIs” is a capability rather than a product and therefore uses a
neutral interface glyph instead of a vendor mark.
